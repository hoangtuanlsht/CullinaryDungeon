# HELLWAKE
### Underground-hell pixel art backgrounds — Firepious (firepious.com)

Below the deepest dungeon, the world keeps going down. Four scenes of the
descent: Hollowfall, Emberflow, Cindervault, Pyreheart.

- 1x: 256x144 native (16:9 — integer-scales x5 = 1280x720, x10 = 2560x1440)
- 4x: 1024x576 nearest-neighbor
- Unified palette across the set; the heat rises as you go down
- Use as static scenes or scrolling backdrops. Godot 4: Sprite2D/TextureRect
  or ParallaxLayer with motion_mirroring; set texture filter to Nearest.
