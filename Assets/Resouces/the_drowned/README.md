# THE DROWNED
### Underwater pixel art backgrounds — Firepious (firepious.com)

The bottom of the river. Four depths of it:
The Descent, The Tower, The Carillon Field, The Silence.

- 1x: 256x144 native (16:9 — integer-scales x5 = 1280x720, x10 = 2560x1440)
- 4x: 1024x576 nearest-neighbor
- The set descends through water zones — teal light to full dark. The color
  progression is intentional; one light source per scene, each dimmer than
  the last.
- Use as static scenes or scrolling backdrops. Godot 4: Sprite2D/TextureRect
  or ParallaxLayer with motion_mirroring; set texture filter to Nearest.
