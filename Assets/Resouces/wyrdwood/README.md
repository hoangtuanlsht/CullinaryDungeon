# WYRDWOOD
### Forest pixel art backgrounds — Firepious (firepious.com)

The old wood. Four rooms of it:
The Eaves, The Hollow, The Clearing, The Heartwood.

- 1x: 256x144 native (16:9 — integer-scales x5 = 1280x720, x10 = 2560x1440)
- 4x: 1024x576 nearest-neighbor
- Under the canopy the forest owns the palette; in the clearing, the night
  does. The color shift is the design — one scene stands open to the sky.
- One light source per scene: the last light, the shaft, the moon, the roots.
- Use as static scenes or scrolling backdrops. Godot 4: Sprite2D/TextureRect
  or ParallaxLayer with motion_mirroring; set texture filter to Nearest.
