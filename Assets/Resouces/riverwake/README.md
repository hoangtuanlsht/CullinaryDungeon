# RIVERWAKE
### River pixel art backgrounds — Firepious (firepious.com)

One evening over the river, four hours of it falling:
The Bank, The Heron, The Drift, The Far Shore.

- 1x: 256x144 native (16:9 — integer-scales x5 = 1280x720, x10 = 2560x1440)
- 4x: 1024x576 nearest-neighbor
- The set follows one dusk from gold to full night — the palette progression
  is intentional; one light source per scene
- Use as static scenes or scrolling backdrops. Godot 4: Sprite2D/TextureRect
  or ParallaxLayer with motion_mirroring; set texture filter to Nearest.
