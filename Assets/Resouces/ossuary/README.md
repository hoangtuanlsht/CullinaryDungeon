# OSSUARY
### Catacomb pixel art backgrounds — Firepious (firepious.com)

The world beneath everything else. One descent through one crypt:
The Door, The Gallery, The Ossuary, The Throne.

- 1x: 256x144 native (16:9 — integer-scales x5 = 1280x720, x10 = 2560x1440)
- 4x: 1024x576 nearest-neighbor
- Unified dark across the set; candlelight holds every scene but one —
  The Ossuary keeps the crypt's single shaft of day
- Interior compositions: doors, galleries, chambers — these sit behind
  dungeon terrain from any other pack.
- Use as static scenes or scrolling backdrops. Godot 4: Sprite2D/TextureRect
  or ParallaxLayer with motion_mirroring; set texture filter to Nearest.
