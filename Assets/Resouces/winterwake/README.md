# WINTERWAKE
### Winter night pixel art backgrounds — Firepious (firepious.com)

The cold above everything else. One night crossing one winter:
The Field, The Pines, The Frozen River, The Aurora.

- 1x: 256x144 native (16:9 — integer-scales x5 = 1280x720, x10 = 2560x1440)
- 4x: 1024x576 nearest-neighbor
- Unified night across the set; the moon holds every scene but one —
  The Aurora hands the sky to the lights
- The Frozen River is Riverwake's river, frozen over — the two packs
  share a world, a season apart.
- Use as static scenes or scrolling backdrops. Godot 4: Sprite2D/TextureRect
  or ParallaxLayer with motion_mirroring; set texture filter to Nearest.
